# Решение: Netlify Identity не просит создать пароль после Accept Invitation

Если после нажатия `Accept invitation` в письме Netlify **не предлагает создать пароль** (или сразу перенаправляет без формы установки пароля), это стандартная проблема с сессиями браузера.

## Причины

1. Вы уже авторизованы в Netlify в этом браузере под другим аккаунтом
2. Приглашение уже было принято ранее
3. Ссылка открывается в той же вкладке с активной сессией

## Решение 1. Открыть ссылку в режиме Инкогнито (самый рабочий)

1. Откройте почту `varangian7221@yandex.ru`
2. Найдите письмо с приглашением от Netlify
3. Скопируйте ссылку `Accept invitation` (ПКМ по кнопке → Копировать ссылку)
4. Откройте **Режим инкогнито** (Ctrl+Shift+N в Chrome/Edge, Ctrl+Shift+P в Firefox)
5. Вставьте скопированную ссылку в адресную строку инкогнито-окна и нажмите Enter
6. Netlify предложит **создать пароль** для аккаунта `varangian7221@yandex.ru` — установите его и сохраните
7. После этого можете закрыть инкогнито и войти в `/admin/` в обычном браузере

## Решение 2. Выйти из Netlify перед принятием

1. В обычном браузере зайдите на [app.netlify.com](https://app.netlify.com/)
2. Нажмите на аватар в правом верхнем углу → `Sign out` (Выйти)
3. Снова откройте письмо с приглашением → нажмите `Accept invitation`
4. Теперь появится форма создания пароля

## Решение 3. Очистить cookies только для Netlify

Если не хотите выходить из всех аккаунтов:

1. В Chrome/Edge: откройте `chrome://settings/content/all` (или Настройки → Конфиденциальность → Файлы cookie)
2. Найдите `netlify.com` → Удалить данные
3. Перезагрузите браузер и откройте ссылку приглашения заново

## Решение 4. Проверить, не принято ли приглашение

1. Зайдите на [app.netlify.com](https://app.netlify.com/) → выберите ваш сайт → `Site configuration → Identity`
2. Посмотрите список `Invite users` / пользователей. Если ваш email уже есть в списке пользователей (не в Pending Invites, а в Users) — приглашение уже принято
3. В этом случае просто заходите в `/admin/` по ссылке `https://ИМЯ-САЙТА.netlify.app/admin/` → `Login with Netlify Identity` → вводите email + пароль (тот, который вы пытались/надеялись создать). Если пароля нет — можно сбросить пароль: на форме входа нажать `Forgot password?` (Забыли пароль) — Netlify пришлёт ссылку для сброса на ваш email.

## Проверка входа в админку

После успешной установки пароля:

1. Перейдите по адресу: `https://ВАШ-САЙТ.netlify.app/admin/`
2. Нажмите `Login with Netlify Identity`
3. Введите `varangian7221@yandex.ru` и созданный пароль
4. Должны попасть в Decap CMS

**Главный совет:** 99% случаев решаются **Решением 1 (Инкогнито)**. Именно его рекомендую использовать для принятия первого приглашения Netlify Identity.
