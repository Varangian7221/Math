# Решение: нет ссылки "Forgot password?" в форме Decap CMS

Иногда в некоторых версиях Decap CMS + Netlify Identity ссылка `Forgot password?` не отображается на встроенной форме. Это нормально.

Есть два рабочих способа сбросить пароль напрямую через Netlify Identity.

## Способ 1. Принудительно открыть форму сброса пароля (URL)

Самый простой — сразу перейти по специальной ссылке на страницу сброса пароля вашего сайта.

Откройте **в режиме Инкогнито** (`Ctrl+Shift+N`) эту ссылку:

```text
https://mathlastname.netlify.app/#/password-reset
```

Если не сработает, попробуйте альтернативный вариант:

```text
https://mathlastname.netlify.app/admin/#/password-reset
```

После открытия должна появиться форма **«Reset password»** (Сброс пароля), где нужно ввести email `varangian7221@yandex.ru` и нажать `Send`.

## Способ 2. Через UI Netlify Identity (гарантированный)

1. Зайдите на [app.netlify.com](https://app.netlify.com/) → выберите ваш сайт `mathlastname`
2. Перейдите в `Site configuration → Identity`
3. Найдите в списке пользователей `varangian7221@yandex.ru`
4. Справа от него есть меню (три точки `...`) или просто нажмите на пользователя
5. Выберите `Delete user` (Удалить пользователя) — **не страшно**, вы потом получите новое приглашение
6. Подтвердите удаление
7. Нажмите `Invite users` → введите `varangian7221@yandex.ru` → `Send invite`
8. Зайдите в [Яндекс.Почту](https://mail.yandex.ru/) → найдите письмо с приглашением от Netlify (самое свежее)
9. Откройте ссылку `Accept invitation` **в режиме Инкогнито** (`Ctrl+Shift+N`)
10. Появится форма `Set your password` — установите новый пароль

Этот способ **100% рабочий**. При удалении и повторном приглашении вы гарантированно получите форму создания пароля без проблем.
