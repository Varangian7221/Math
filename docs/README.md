## Устаревшие

Остальные файлы в `docs/` — история неудачных попыток настроить вход через
**Netlify Identity OAuth и Git Gateway OAuth**. Актуальный способ —
`git-gateway` + Identity, описан в `НАСТРОЙКА_ВХОДА_В_АДМИНКУ.md`.

Важно: почти все эти файлы описывают проблемы, которые на самом деле
вызывались багом с `/admin/` (отдавался `admin.html` вместо Decap CMS).
Баг исправлен, инструкции ниже — исторические.
