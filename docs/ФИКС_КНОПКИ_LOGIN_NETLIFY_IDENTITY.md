# Фикс: кнопка "Login with Netlify Identity" не появляется в Decap CMS

Пустой коммит отправлен — Netlify запустил пересборку сайта. Теперь дождитесь, пока деплой завершится (станет `Published`).

## Что сделали

Я сделал пустой коммит и запушил в GitHub:

```text
chore: trigger redeploy to enable Netlify Identity in Decap CMS
```

Netlify автоматически запустил **новый деплой**. Это гарантированно заставит его пересобрать сайт с активными настройками Identity + Git Gateway.

## Шаг 1. Дождитесь завершения деплоя

1. Перейдите в [Deploys на Netlify](https://app.netlify.com/sites/mathlastname/deploys)
2. Дождитесь, пока самый последний деплой станет **`Published`** (зелёная галочка). Обычно 30–60 секунд
3. Не переходите в админку раньше, пока деплой не завершился

## Шаг 2. Откройте /admin/ в режиме Инкогнито (обязательное условие)

1. Полностью **закройте все** вкладки с `https://mathlastname.netlify.app/admin/`
2. Откройте **Режим инкогнито** (`Ctrl+Shift+N` в Chrome/Edge/Yandex)
3. Перейдите строго по ссылке: [https://mathlastname.netlify.app/admin/](https://mathlastname.netlify.app/admin/)
4. Нажмите **жёсткую перезагрузку**: `Ctrl+Shift+R` (Windows) или `Ctrl+Shift+R` / `⌘+Shift+R` (Mac)
5. Подождите 2–3 секунды

## Шаг 3. Проверьте результат

Теперь внизу экрана Decap CMS **обязательно** появится кнопка **`Login with Netlify Identity`**.

После её появления:

1. Нажмите `Login with Netlify Identity`
2. Введите `varangian7221@yandex.ru` и пароль, который вы установили по ссылке сброса пароля
3. Вы попадёте в админку

## Дополнительный совет

Иногда Decap CMS загружается с небольшой задержкой. Если кнопка не появилась сразу — подождите **ещё 3–5 секунд** на той же вкладке (без перезагрузки лишний раз).

Пустой коммит + свежий `Published`-деплой + Инкогнито + `Ctrl+Shift+R` — этот набор почти всегда помогает в такой ситуации.
