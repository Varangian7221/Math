# Вход в админку: что было сломано и как настроить правильно

Админка: **https://mathlastname.netlify.app/admin/**

---

## ⚠️ Сначала — важная поправка

Ранее я предлагал зарегистрировать OAuth-приложение на GitHub и добавить
`GITHUB_CLIENT_ID` / `GITHUB_CLIENT_SECRET` в Netlify.

**Это не нужно. Отзываю ту рекомендацию.**

Я проверил код Decap CMS 3.16.3 — реально исполняемый, из того же бандла, что
грузит браузер. Вот что там написано:

```js
// аутентификатор, который использует backend `github`
let url = `${base_url}/${auth_endpoint}?provider=github&site_id=${siteId}&scope=repo`;
window.open(url, ...);
```

Он **не умеет передавать `client_id`** — вообще. А endpoint, который он строит
по умолчанию:

```
https://api.netlify.com/auth?provider=github&site_id=...&scope=repo
```

**отдаёт `404 Not Found`.** Проверено напрямую:

| Адрес | Ответ |
|---|---|
| `api.netlify.com/auth?...` | `404` ← Decap стучится сюда |
| `api.netlify.com/oauth/authorize` | `400 Missing required parameter: client_id` |
| `api.netlify.com/oauth/authorize?client_id=...` | `401 unknown client` |

То есть посредник авторизации Netlify для этого сценария непригоден: Decap не
передаёт `client_id`, а Netlify его требует. Схема `github` + `base_url` —
тупик, независимо от того, что вы впишете в GitHub и Netlify.

## ✅ Что работает: `git-gateway`

Это штатный и единственный поддерживаемый путь Decap на Netlify.
`admin/config.yml` теперь такой:

```yaml
backend:
  name: git-gateway
  branch: main
```

`git-gateway` обращается к `/.netlify/identity` и `/.netlify/git` — эти
endpoint-ы на Netlify живут и работают.

## Главное, что раньше мешало

Все прошлые попытки настроить вход были **бесполезны из-за бага в самой странице**.

Netlify по адресу `/admin/` отдавал **корневой `admin.html`** (Node-админку),
а не `admin/index.html` с Decap CMS. Из-за «Pretty URLs» корень имеет приоритет
над папкой.

Вы видели не форму Identity, а поле `Password` от Node-админки — поэтому:

- не было ссылки `Forgot password?`
- `Set your password` не появлялась
- в консоли `api/session 404`

**Баг исправлен** — файл переименован в `admin-node.html`, `/admin/` теперь
отдаёт настоящий Decap CMS. Теперь настройка Identity/Git Gateway впервые
имеет смысл — раньше вы настраивали то, что не открывалось.

## Что сделать (один раз)

### 1. Включить Identity

`app.netlify.com` → сайт `mathlastname` → `Site configuration` → `Identity` →
`Enable Identity`.

> По умолчанию включён Registration → Invite only. Для себя этого достаточно.

### 2. Включить Git Gateway

Там же → `Identity` → `Services` → `Git Gateway` → **Enable**.

Привязка к репозиторию: `https://github.com/Varangian7221/Math`.

### 3. Пригласить себя

`Identity` → `Users` → `Invite users` → укажите почту, на которую точно
приходит письмо → `Send invite`.

> Раньше был расхождение: в Users был `varangian7221@gmail.com`, а вы
> проверяли `varangian7221@yandex.ru`. Убедитесь, что адрес один и тот же.

### 4. Открыть инвайт

Письмо придёт от Netlify. Скопируйте ссылку **целиком** и откройте её.

Форма `Set your password` отрисуется **внутри той же страницы** — это SPA,
отдельной вкладки не будет. Просто подождите 5–10 секунд после загрузки.

### 5. Войти

`https://mathlastname.netlify.app/admin/` → введите почту и пароль →
редактор откроется.

## Если что-то не работает

| Симптом | Причина |
|---|---|
| `/admin/` показывает форму с одним полем `Password` | снова открылся `admin.html` — проверьте, что он переименован |
| `api/session 404` в консоли | то же самое |
| Кнопки входа нет, страница пустая | не загрузился `https://unpkg.com/decap-cms@^3.3.3/dist/decap-cms.js` |
| `Error: You don't have sufficient permissions to access Decap CMS` | пользователь не добавлен в collaborators репозитория |
| Письмо-приглашение не приходит | адрес в `Identity → Users` не совпадает с тем, куда вы смотрите |

## Запасные пути (работают всегда)

**1. Правка `data/content.json` напрямую на GitHub.**
Файл `data/content.json` → кнопка карандаша → правка → commit.
Netlify пересоберёт сайт за 30–90 секунд. Формат тот же, что в админке.

**2. Node-админка.**
`/admin-node.html` при запуске через `node server.js`. Свой пароль, свой API,
никаких внешних сервисов.
