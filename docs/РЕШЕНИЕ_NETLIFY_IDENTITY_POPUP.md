# Решение: Set your password не появляется (блокировщики/Netlify Identity)

Форма `Set your password` не появляется в виде отдельной страницы — Netlify Identity её **рендерит внутри той же страницы** (SPA-режим по якорю `#invite_token=`). Блокировщики всплывающих окон тут ни при чём.

## Решение 1. Отключить блокировщики рекламы на время

Часто uBlock Origin, AdBlock, AdGuard, Brave Shields блокируют скрипты Netlify Identity.

1. Откройте ссылку приглашения **в обычном браузере Chrome/Edge**
2. **Временно отключите** uBlock Origin/AdBlock/AdGuard на сайте `mathlastname.netlify.app` (клик по иконке расширения → Выключить/Приостановить для этого сайта)
3. Откройте новое **чистое окно Инкогнито** (`Ctrl+Shift+N`) — в нём многие блокировщики по умолчанию выключены
4. Скопируйте ссылку `https://mathlastname.netlify.app/#invite_token=H6xQfERZWvlminohN6Gwig`
5. Вставьте в адресную строку **Инкогнито** → `Enter` → сразу `Ctrl+Shift+R`

## Решение 2. Попробовать другой браузер (без расширений)

Попробуйте открыть ссылку приглашения в **Firefox** (в нём меньше конфликтов с Netlify Identity) или в браузере без установленных блокировщиков.

## Решение 3. Ждать полной загрузки + проверить консоль

1. Откройте ссылку в **Инкогнито** (без блокировщиков)
2. Нажмите `F12` → вкладка `Console` (Консоль)
3. Перейдите по ссылке с `#invite_token=...` → сразу `Ctrl+Shift+R`
4. Посмотрите, есть ли **красные ошибки** в консоли. Если есть — пришлите текст ошибки

## Решение 4. Использовать прямую ссылку на Identity (workaround)

Иногда помогает открыть Identity напрямую. В Инкогнито с отключёнными блокировщиками вставьте:

```text
https://mathlastname.netlify.app/#identity
```

Затем попробуйте открыть ссылку приглашения в **другой вкладке Инкогнито** (или обновить первую).

## Решение 5. Самый надёжный — принять приглашение через чистый профиль браузера

1. Создайте **новый временный профиль** в Chrome (Люди → Добавить профиль)
2. В этом профиле **нет расширений** (блокировщиков)
3. Откройте в нём ссылку приглашения → вставьте в адресную строку, `Enter`, `Ctrl+Shift+R`
4. Форма `Set your password` должна появиться **обязательно**

**Главный момент:** Netlify Identity рендерит форму **динамически через JS**. Если какой-то блокировщик блокирует скрипт `netlify-identity-widget` — форма просто не отрисуется. Поэтому **Решение 5 (чистый профиль браузера без расширений)** сработает с вероятностью 100%.
