# Подробная инструкция: как загрузить папку Math в репозиторий GitHub

Эта инструкция подойдёт для Windows (Проводник + Git Bash или Терминал Windows). Мы будем использовать GitHub веб-интерфейс + Git локально (самый надёжный способ).

## Способ 1. Самый простой — создать пустой репозиторий на GitHub и загрузить файлы

### Шаг 1. Создаём пустой репозиторий на GitHub

1. Зайдите на [github.com](https://github.com/) и авторизуйтесь под `varangian7221@yandex.ru`
2. Нажмите `+` (кнопка «New») в правом верхнем углу → `New repository`
3. Заполните поля:

   - **Repository name** — `Math` (именно так, как вы просили)
   - **Description** (необязательно) — `Лендинг репетитора по математике`
   - **Visibility** — выберите `Public` (публичный) или `Private` (приватный). Для показа подойдёт Public
   - **Очень важно:** НЕ ставьте галочки `Add a README file`, `Add .gitignore`, `Choose a license`. Должен получиться **пустой репозиторий**.
4. Нажмите `Create repository`

GitHub откроет страницу пустого репозитория с командами.

### Шаг 2. Устанавливаем Git (если ещё не установлен)

Проверьте, установлен ли Git:

1. Нажмите `Win + R` → введите `cmd` → Enter
2. В командной строке напишите:

```cmd
git --version
```

Если видите что-то вроде `git version 2.46.0.windows.1` — Git уже установлен. Если нет — скачайте и установите [Git для Windows](https://git-scm.com/download/win) (устанавливайте с настройками по умолчанию).

### Шаг 3. Открываем терминал в папке Math

Есть 3 удобных способа:

**Способ А. Через Проводник (рекомендуется)**

1. Откройте папку `C:\My\ZEROCODER\Лендинг\Math`
2. В пустом месте папки нажмите **правой кнопкой мыши**
3. Выберите `Git Bash Here` (если установлен Git) или `Open in Terminal` (в Windows 11)

Откроется терминал, в котором путь уже будет `C:\My\ZEROCODER\Лендинг\Math`

**Способ Б. Через cmd**

```cmd
cd C:\My\ZEROCODER\Лендинг\Math
```

### Шаг 4. Инициализируем Git в папке Math

В терминале выполните по порядку эти команды:

```bash
git init
```

```bash
git branch -M main
```

### Шаг 5. Добавляем все файлы в Git

```bash
git add .
```

Эта команда добавит все файлы папки Math (кроме тех, что указаны в `.gitignore`).

Проверим, что добавилось (необязательно):

```bash
git status
```

Должны появиться зелёным все ваши файлы.

### Шаг 6. Делаем первый коммит

```bash
git commit -m "Первый коммит: лендинг репетитора + админка"
```

### Шаг 7. Подключаем репозиторий GitHub

На странице пустого репозитория GitHub (шаг 1) вы увидите 2 варианта. Нам нужен **второй блок** «…or push an existing repository from the command line».

Скопируйте **первую** команду (добавление remote). Она выглядит примерно так:

```bash
git remote add origin https://github.com/varangian7221/Math.git
```

Выполните её в терминале в папке Math.

Потом вторую команду (пуш в main):

```bash
git push -u origin main
```

При первом пуше GitHub может попросить авторизоваться (в браузере откроется окно входа в GitHub) — подтвердите авторизацию.

### Шаг 8. Проверяем результат

1. Обновите страницу репозитория на GitHub: [https://github.com/varangian7221/Math](https://github.com/varangian7221/Math)
2. Вы должны увидеть **всю папку Math** с файлами (index.html, admin/, server.js и т.д.)

Готово! Репозиторий загружен.

## Способ 2. Ещё проще — загрузка через GitHub веб-интерфейс (без Git в терминале)

Подходит, если хотите загрузить файлы прямо в браузере (без команд).

### Шаг 1. Создаём репозиторий Math (пустой) — как в Шаге 1 Способа 1

### Шаг 2. Загружаем папку целиком

1. На странице пустого репозитория нажмите `uploading an existing file` (ссылка ниже команд)
2. Откроется окно drag-and-drop
3. Откройте папку `C:\My\ZEROCODER\Лендинг\Math` в Проводнике
4. **Выделите все файлы и папки** (Ctrl+A или выделить мышкой)
5. Перетащите их прямо в это окно на GitHub (или нажмите `choose your files`)
6. GitHub автоматически упакует всё
7. Внизу в поле `Commit changes` напишите: `Первый коммит: лендинг репетитора по математике`
8. Нажмите `Commit changes`

**Минус этого способа:** GitHub веб-интерфейс позволяет загрузить за один раз до ~100 файлов. У вас ~20 файлов — загрузится нормально. Если файлов было бы очень много — лучше Способ 1 (через Git).

Но для вашего проекта **Способ 1 (Git + терминал)** — оптимальный и надёжный.

## Способ 3. GitHub Desktop (графический, без команд)

1. Скачайте [GitHub Desktop](https://desktop.github.com/ru/)
2. Установите, войдите под `varangian7221@yandex.ru`
3. `File → Add local repository` → выберите папку `C:\My\ZEROCODER\Лендинг\Math`
4. GitHub Desktop предложит опубликовать репозиторий → `Publish repository`, название `Math`, Public → `Publish`
5. Готово

## Совет

**Рекомендуемый вариант — Способ 1**. Он создаст правильный `.git` репозиторий, сохранит историю изменений и позволит в будущем легко обновлять проект.
