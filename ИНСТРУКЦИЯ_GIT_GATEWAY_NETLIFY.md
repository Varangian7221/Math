# Подробная инструкция: Включение Git Gateway на Netlify (для Decap CMS)

Эта инструкция нужна для того, чтобы админка Decap CMS (`/admin/`) заработала на статическом хостинге Netlify и могла сохранять изменения прямо в GitHub.

## Шаг 1. Подключаем репозиторий Math к Netlify

1. Зайдите на [app.netlify.com](https://app.netlify.com/) и авторизуйтесь
2. Нажмите `Add new site` (Добавить новый сайт) → `Import an existing project` (Импортировать существующий проект)
3. Выберите `GitHub` (авторизуйтесь, если потребуется)
4. Найдите репозиторий `Math` (ваш репозиторий `varangian7221/Math`) и выберите его
5. На экране настройки сборки оставьте всё пустым:

   - **Build command** — оставьте пустым
   - **Publish directory** — оставьте пустым (или `.`, Netlify определит автоматически для статического сайта)
6. Нажмите `Deploy site` (Развернуть сайт)
7. Подождите 1–2 минуты. Netlify создаст сайт и выдаст адрес вида `https://something-random-12345.netlify.app/`

Сайт должен открыться по этой ссылке (лендинг отобразится).

## Шаг 2. Включаем Identity (Идентификация)

1. В панели управления сайтом на Netlify перейдите в раздел `Site configuration` (Конфигурация сайта) — в левом боковом меню (внизу или в разделе Settings)
2. В открывшемся меню выберите `Identity` (Идентификация)
3. Нажмите `Enable Identity` (Включить идентификацию)
4. Подождите несколько секунд, пока Identity включится

## Шаг 3. Включаем Git Gateway

1. После включения Identity в этом же разделе `Site configuration → Identity` прокрутите вниз
2. Найдите блок `Git Gateway` (Git-шлюз)
3. Нажмите `Enable Git Gateway` (Включить Git Gateway)
4. Появится всплывающее окно с подтверждением — нажмите `Enable` (Подтвердить)
5. Git Gateway подключится к вашему репозиторию GitHub. Обычно активация занимает 5–15 секунд

## Шаг 4. Настраиваем регистрацию пользователей (ограничиваем доступ только себе)

Чтобы никто, кроме вас, не мог войти в админку — ограничим регистрацию.

1. Всё ещё в `Site configuration → Identity`
2. Прокрутите вниз до блока `Registration preferences` (Настройки регистрации)
3. Нажмите `Edit settings` (Изменить настройки)
4. Выберите `Invite only` (Только по приглашениям)
5. Сохраните изменения

Теперь зарегистрироваться самостоятельно нельзя — вы будете приглашать только нужных людей (в вашем случае только себя).

## Шаг 5. Приглашаем себя в админку

1. В разделе `Identity` нажмите `Invite users` (Пригласить пользователей)
2. В поле `Email address` введите ваш email: **`varangian7221@yandex.ru`**
3. Нажмите `Send invite` (Отправить приглашение)

Netlify отправит письмо с приглашением на этот почтовый ящик.

## Шаг 6. Принимаем приглашение

1. Откройте почту `varangian7221@yandex.ru` (Яндекс.Почта)
2. Найдите письмо от Netlify с темой типа `You've been invited to join [имя-сайта] on Netlify`
3. Нажмите кнопку `Accept invitation` (Принять приглашение) в письме
4. Вас перенаправит на Netlify, где предложат задать пароль для входа в админку
5. Придумайте и задайте пароль (запомните его)
6. Подтвердите пароль → вход выполнен

## Шаг 7. Заходим в админку Decap CMS

1. Перейдите по адресу вашей админки:

```text
https://ИМЯ-ВАШЕГО-САЙТА.netlify.app/admin/
```

Замените `ИМЯ-ВАШЕГО-САЙТА` на адрес, который Netlify выдал в Шаге 1 (например `https://math-teacher.netlify.app/admin/`).

2. Нажмите `Login with Netlify Identity` (Войти через Netlify Identity)
3. Введите email `varangian7221@yandex.ru` и пароль, который вы только что создали
4. Готово — вы в админке Decap CMS!

Теперь вы можете редактировать все тексты, загружать фото, нажимать `Save` — изменения автоматически создадут коммит в репозитории GitHub, и Netlify пересоберёт сайт (задержка обычно 30–90 секунд).

## Важные подсказки

- **Адрес админки всегда заканчивается на `/admin/`** (со слэшем). Без слэша может не загрузиться.
- **Только вы можете входить** — благодаря `Invite only`.
- **Изменения публикуются автоматически** — после сохранения в CMS сайт обновится сам через ~1 минуту.
- **Фото** загружаются в `images/uploads/` (как и настроено в `config.yml`). Они не попадут в Git (по `.gitignore`), но на Netlify при пересборке статики загруженные фото не хранятся автоматически. Если вы часто будете загружать новые фото — лучше либо убрать исключение `images/uploads/*` из `.gitignore`, либо использовать внешнее хранилище. Но для базовых правок SVG-заглушки заменяются новыми WebP — можно оставить как есть.
- **Если письмо с приглашением не пришло** — проверьте папку «Спам» в Яндекс.Почте.
