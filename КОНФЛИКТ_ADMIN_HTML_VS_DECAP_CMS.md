# Объяснение ошибки 404 /api/session

Ошибка

```text
api/session:1 Failed to load resource: the server responded with a status of 404 ()
```

возникает потому, что вы сейчас заходите на **статический хостинг Netlify** (где работает только Decap CMS), а в вашем проекте остался **файл `admin.html`** (Node.js-версия админки).

Decap CMS не использует `/api/session`. Этот запрос делает **JavaScript из `admin.html`** (Node.js-админка). Когда браузер загружает `/admin/` (Decap CMS), он может подхватывать или пытаться выполнить какой-то общий JS? Или вы случайно открыли не ту админку.

## В чём разница между двумя админками

У вас **два разных варианта**:

| Вариант | Адрес | Работает на | Как сохраняет |
|---|---|---|---|
| **A. Node.js** | `/admin.html` | Хостинги с Node.js (Render, Railway) | Через API `/api/*` (сохраняет в `data/content.json` мгновенно) |
| **B. Decap CMS** | `/admin/` (папка) | Статический (Netlify, Cloudflare Pages) | Делает коммиты в GitHub (через Git Gateway) |

**Запрос `/api/session` существует только в Варианте A (Node.js-админке)**. У Decap CMS таких API-эндпоинтов нет — он вообще не обращается к `/api/session`.

## Почему ошибка 404 появляется на Netlify

Ошибка `/api/session 404` значит, что страница **пытается загрузить JS от Node-админки**.

Вероятные причины:
1. Вы открыли `https://mathlastname.netlify.app/admin.html` вместо `https://mathlastname.netlify.app/admin/`
2. Браузер закэшировал что-то (JS, редирект)
3. Какой-то файл остался и пытается выполниться

## Что нужно делать на Netlify (Decap CMS)

**Правильный адрес для Netlify — только `/admin/`** (со слэшем, папка `admin/index.html`).

**НЕ открывайте `/admin.html` на Netlify.** Файл `admin.html` там физически есть (статический файл), и при его открытии браузер загружает `js/admin.js` от Node-версии, который сразу делает `fetch('/api/session')` → на статическом хостинге этот API не существует → 404.

## Исправление

1. **Закройте все вкладки** с админкой
2. Откройте **Режим инкогнито** (`Ctrl+Shift+N`)
3. Перейдите **строго** по этой ссылке (обязательно со слэшем):

```text
https://mathlastname.netlify.app/admin/
```

**Не** `admin.html`, а именно `/admin/`

4. Сделайте `Ctrl+Shift+R` (жёсткая перезагрузка)
5. Подождите полную загрузку (10–15 секунд)
6. **Прокрутите страницу вниз до самого низа** — кнопка `Login with Netlify Identity` появится там

## Проверка

В консоли DevTools после открытия `/admin/` (со слэшем) **не должно** быть ошибки `/api/session 404`. Если ошибка осталась — вы открыли не тот URL.

Главный вывод: на **Netlify** используйте **`/admin/`**. На хостинге с **Node.js** используйте **`/admin.html`**. Эти админки разные и не должны путаться.
