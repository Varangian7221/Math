# Исправление: Git Gateway не становится зелёным (статус не «Enabled»)

У вас на скриншоте видно: в блоке **Git Gateway** нет зелёного статуса `Git Gateway is enabled`. Он либо серый, либо висит в состоянии подключения — из-за этого Decap CMS не показывает кнопку `Login with Netlify Identity`.

## Почему так происходит

Чаще всего Git Gateway не включается сразу, если:
1. Репозиторий был подключён недавно (ещё идёт первичная связка)
2. Identity только что включили
3. Есть небольшая задержка в связке Netlify ↔ GitHub

## Решение 1. Подождать и обновить страницу

1. На странице `Site configuration → Identity` посмотрите на блок `Git Gateway`
2. Если там крутится спиннер/надпись `Connecting...` или `Enabling...` — **подождите 30–60 секунд** (не нажимайте много раз)
3. Обновите страницу (`F5`) в браузере
4. Посмотрите, появился ли зелёный текст `Git Gateway is enabled`

Очень часто он включается сам, просто с задержкой.

## Решение 2. Отключить и включить Git Gateway повторно

Если статус так и не стал зелёным через минуту:

1. В блоке `Git Gateway` нажмите `Disable Git Gateway` (Отключить), если такая кнопка есть. Если кнопка только `Enable Git Gateway` — пропустите этот шаг
2. Подождите 5–10 секунд
3. Нажмите `Enable Git Gateway` (Включить Git Gateway)
4. Появится окно подтверждения → `Enable`
5. **Подождите 30–60 секунд** (не закрывайте страницу)
6. Обновите страницу (`F5`) — статус должен стать зелёным

## Решение 3. Выключить и включить Identity полностью (жёсткий способ)

Иногда помогает полная перезагрузка связки:

1. Перейдите `Site configuration → Identity`
2. Нажмите `Disable Identity` (в самом низу раздела Identity, в Danger Zone)
3. Подтвердите отключение
4. Подождите 10 секунд → обновите страницу
5. Нажмите `Enable Identity` обратно
6. После того, как Identity включился (зелёный статус сверху) — подождите 10 секунд
7. Нажмите `Enable Git Gateway` → подтвердите
8. Подождите **60 секунд** → обновите страницу (`F5`)
9. Блок `Git Gateway` должен стать зелёным: `Git Gateway is enabled`

## Решение 4. Проверить права доступа к репозиторию (GitHub)

Git Gateway требует, чтобы Netlify имел доступ к репозиторию.

1. Зайдите в [app.netlify.com](https://app.netlify.com/) → ваш сайт → `Site configuration → Build & deploy → Continuous Deployment → Repository`
2. Убедитесь, что репозиторий указан как `varangian7221/Math` (GitHub)
3. Если есть кнопка `Reconnect repository` — нажмите её, выберите репозиторий повторно и дайте все необходимые разрешения GitHub

## Шаг 5. После того, как Git Gateway станет ЗЕЛЁНЫМ

Только **после** того, как в блоке `Git Gateway` появится зелёный текст `Git Gateway is enabled`:

1. Перейдите во вкладку `Deploys` → `Trigger deploy → Deploy site` (сделайте **принудительный редеплой**)
2. Дождитесь, пока деплой станет `Published` (зелёный)
3. Откройте [https://mathlastname.netlify.app/admin/](https://mathlastname.netlify.app/admin/) в **Режиме инкогнито** (`Ctrl+Shift+N`)
4. Сделайте `Ctrl+Shift+R` (жёсткая перезагрузка)
5. Кнопка **`Login with Netlify Identity`** должна появиться

## Главный вывод

Пока `Git Gateway` не горит **зелёным** — кнопки входа в админке не будет. Решение 2 (отключить/включить Git Gateway с паузой в 30–60 секунд) с последующим обновлением страницы (`F5`) помогает чаще всего.
