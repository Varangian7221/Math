# Лендинг преподавателя математики

Одностраничный сайт: светлый минимализм, чёткая типографика, акцент на фото и тексте.
Без сборки и зависимостей — просто откройте `index.html` в браузере.

---

## 📁 Структура

```
Math/
├── index.html          — вся страница (тексты, цены, отзывы правятся здесь)
├── css/
│   └── styles.css      — стили, цвета, адаптив
├── js/
│   ├── config.js       — ⭐ ИМЯ, ТЕЛЕФОН, TELEGRAM, WHATSAPP, ТОКЕН БОТА
│   └── script.js       — маска телефона, валидация, отправка заявки, анимации
├── images/
│   ├── teacher-1.svg   — заглушка фото 4:5 (первый экран)
│   ├── teacher-2.svg   — заглушка фото 1:1 (блок «Обо мне»)
│   └── favicon.svg     — иконка сайта
├── preview-desktop.png — скриншот собранной страницы
└── README.md
```

## ✏️ Что и где менять

### 1. Имя и контакты → `js/config.js`

Всё в одном объекте `window.SITE`. Правка применяется сразу в шапке, первом экране,
блоке «Обо мне», подвале, липкой мобильной панели и кнопках мессенджеров.

```js
teacher:  { firstName: 'Анна', lastName: 'Смирнова', full: 'Анна Смирнова' },
contacts: {
  phone:         '+7 900 000-00-00',   // как видит посетитель
  phoneHref:     '+79000000000',        // формат для ссылки «Позвонить»
  telegram:      'https://t.me/username',
  whatsapp:      'https://wa.me/79000000000',
  email:         'mail@example.com'
}
```

### 2. Тексты, цены и отзывы → `index.html`

Все блоки подписаны комментариями, ищите по ним:

| Что меняете | Что искать в коде |
|---|---|
| Заголовок первого экрана | `hero__title` |
| Обещания (УТП) | `id="utp"` |
| Боли | `id="pains"` |
| Решение | `id="solution"` |
| Обо мне, достижения | `id="about"` |
| Направления | `id="directions"` |
| Почему стоит заниматься | `id="why"` |
| Отзывы | `id="reviews"` |
| Тарифы и цены | `id="prices"`, `price__value` |
| Вопросы-ответы | `id="faq"` |
| Текст формы и срочность | `id="contact"` |

> ⚠️ Отзывы и FAQ продублированы в разметке Schema.org (`FAQPage`) в `<head>` —
> при замене текста вопросов поправьте и его, чтобы поисковики не показывали устаревшее.

### 3. Цвета и шрифт → `css/styles.css`, блок `:root` (в самом верху)

```css
--accent: #2350d6;   /* основной синий: кнопки, ссылки, акценты */
--warm:   #b4501e;   /* тёплый акцент для блока «боли» */
--bg:     #ffffff;   /* фон */
--bg-soft:#f6f7f4;   /* фон чередующихся секций */
--ink:    #0f1419;   /* текст */
```

Чтобы взять зелёный вместо синего — поменяйте только `--accent` (и `--accent-dark`,
`--accent-soft`, `--accent-line`).

## 📸 Как поставить своё фото

1. Сделайте WebP (сайт требует именно WebP — он легче JPEG в 1.5–2 раза).
   Онлайн-конвертеры: `squoosh.app`, `webp-converter.io`.
   - Первый экран — **800 × 1000 px** (соотношение 4:5), качество 80.
   - Блок «Обо мне» — **720 × 720 px** (1:1), качество 80.
   - Обрезайте по линии плеч/плеч, чтобы лицо было в верхней трети.
2. Положите файлы в `images/` как `teacher-1.webp` и `teacher-2.webp`.
3. В `index.html` замените `.svg` на `.webp` в двух местах (поиск: `images/teacher`):

```html
<img src="images/teacher-1.webp" ... >
<img src="images/teacher-2.webp" ... >
```

Второе фото подгружается лениво (`loading="lazy"`), поэтому скорость не пострадает.

**Для соцсетей** сохраните кадр 1200 × 630 px как `images/og-cover.jpg` —
это картинка, которая показывается при отправке ссылки в мессенджерах.

## 🤖 Как подключить Telegram-бота для заявок

### Вариант 1 — бот (заявка приходит сама)

1. Откройте `@BotFather` → `/newbot` → скопируйте токен.
2. Напишите вашему боту любое сообщение (это нужно, чтобы бот «увидел» чат).
3. Откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
   и найдите `"chat":{"id": 123456789}` — это ваш `CHAT_ID`.
4. Впишите оба значения в `js/config.js`:

```js
telegramBot: {
  token:  '7123456789:AAH...',
  chatId: '123456789'
}
```

Готово. Форма сама отправляет сообщение вам в Telegram и показывает посетителю
экран «Заявка отправлена» со ссылкой на календарь.

> При желании добавьте кнопку «Бот → Настройки → Заменить URL» на бесплатном
> [ManyBot](https://manybot.io) — тогда сообщение будет приходить и в виде
> красивой карточки с кнопкой.

### Вариант 2 — без бота (работает сразу)

Оставьте `token` и `chatId` пустыми. Тогда при отправке формы посетитель
получает готовое сообщение и кнопку «Отправить заявку в Telegram» — текст
подставится сам. Ничего не теряется, ничего не настраивать не нужно.

## 🎨 Настройки под требования из брифа

| Требование | Как сделано |
|---|---|
| Адаптив, приоритет мобильным | Контрольные точки 1080 / 920 / 640 / 380 px. Проверено на 360, 390, 768, 1440 px |
| Закреплённая кнопка внизу (мобильная) | `.stickybar` — Telegram + «Записаться на диагностику», появляется после первого экрана |
| Лёгкая загрузка | Один CSS, один JS, нет библиотек и фреймворков. Шрифт грузится неблокирующе, фото — `lazy` |
| Без тяжёлых анимаций | Только `transform`/`opacity` на 0.55 с. Полностью отключаются при `prefers-reduced-motion` |
| Только реальное фото, без стоков | Заглушки-заполнители, заменяются на ваше фото (см. выше) |
| Формы → Telegram + автоответ | `js/script.js`, экран успеха со ссылкой на календарь (`calendar` в `config.js`) |
| Домен + SSL | Деплой на любой хостинг с бесплатным SSL. Поправьте `canonical` и `og:url`/`og:image` в `<head>` на свой домен |

## ✅ Реализовано

- **SEO**: `title`, `description`, `keywords`, `canonical`, Open Graph, Twitter Card, Schema.org (`Person` + `FAQPage`), семантические `h1`–`h3`, `alt` у картинок, `skip-link`.
- **Форма**: маска телефона `+7 (___) ___-__-__`, валидация всех полей, подсветка ошибок, согласие на обработку данных, автофокус на первое проблемное поле.
- **Удобство**: плавная прокрутка с учётом шапки, FAQ на нативном `<details>`, год в подвале ставится автоматически.
- **Доступность**: контрастные цвета, видимый фокус, `aria-label` у звёзд рейтинга, поддержка `prefers-reduced-motion`.

## 🚀 Как запустить

Двойной клик по `index.html` — и всё работает.

Для проверки с телефона в локальной сети:

```bash
python -m http.server 8000
```

затем откройте `http://<IP-компьютера>:8000` на телефоне.
